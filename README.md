# Project Showcase Portfolio

A highly interactive and professional software engineering portfolio designed to showcase your best projects. The application features dynamic animations, a responsive design, a premium glassmorphism user interface, and dedicated project case study pages with built-in video playback capabilities.

## 🚀 Features

- **Dynamic Hero Section**: A full-bleed responsive hero banner with optimized background overlays to ensure text clarity and high contrast.
- **Interactive Project Cards**: Beautifully animated project tiles using Framer Motion. Cards feature smooth hover states, delay-free interactions, and prominent responsive borders.
- **Dedicated Case Studies**: Dynamic routing (`[id].astro`) that generates individual case study pages for every project, displaying detailed descriptions, tech stacks, and key metrics.
- **Video Showcases**: Built-in video players for project demonstrations, equipped with basic protections to prevent video downloading and right-clicking.
- **Modern UI & Animations**: A premium aesthetic utilizing a custom Tailwind CSS color palette (Cyan/Sky Blue/Teal), glassmorphism effects, gradient text, and fluid page transitions.
- **Responsive Design**: Carefully crafted layouts ensuring that project metrics, cards, and typography scale perfectly from large desktop monitors down to mobile screens.

## 💻 Tech Stack

| Technology | Role | Description |
| :--- | :--- | :--- |
| **Astro** | Meta-Framework | Handles the core static site generation, fast page loads, and dynamic routing logic. |
| **React** | UI Library | Powers the interactive client-side components like the `ProjectTile` and `WelcomeGreeting`. |
| **Tailwind CSS** | Styling | Provides the utility-first CSS framework used for layout, typography, and custom color theming. |
| **Framer Motion** | Animation | Drives the fluid entrance animations, staggered load effects, and smooth interactive hover states. |
| **Lucide React** | Iconography | Supplies the clean, professional SVG icons used throughout the case study pages. |
